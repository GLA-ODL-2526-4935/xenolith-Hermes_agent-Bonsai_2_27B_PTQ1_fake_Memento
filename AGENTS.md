# Combined-project setup instructions

For setup/compatibility requests, read the top-level [Agent.md](Agent.md) in full
before acting. It requires hardware inspection first, explicit engine/model
choices before downloads, and approval before installing or running workloads.

This guide is separate from `Hermes_agent/AGENTS.md`. When editing nested code,
also follow that directory's applicable AGENTS instructions. Documentation-only
requests do not authorize setup, model loading, driver changes or GPU execution.
